## 🔧 Troubleshooting

|--------------|---------------|
| **Too many false positives** | Use AST mode |
| **Scan too slow** | Add ignore paths |
| **Score doesn't drop** | Refactor deep clones |
| **Crash on big repos** | Increase RAM |
| **CI times out** | Cache results |
| **Wrong matches** | Update language plugins |
